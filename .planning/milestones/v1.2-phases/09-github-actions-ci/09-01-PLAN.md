  <name>Task 1: Add CI release signing config to build.gradle.kts</name>
  <files>app/build.gradle.kts</files>
  <action>
Modify `app/build.gradle.kts` to add a `release` signing config that reads credentials from environment variables. The release build type should use this CI signing config when the environment variables are present, falling back to the debug signing config for local development.

**Add a `release` signing config** inside the existing `signingConfigs` block (after the `debug` config):

```kotlin
signingConfigs {
    getByName("debug") {
        // Uses default debug keystore at ~/.android/debug.keystore
    }
    create("release") {
        val keystorePath = System.getenv("SIGNING_KEYSTORE_PATH")
        if (keystorePath != null) {
            storeFile = file(keystorePath)
            storePassword = System.getenv("SIGNING_STORE_PASSWORD")
            keyAlias = System.getenv("SIGNING_KEY_ALIAS")
            keyPassword = System.getenv("SIGNING_KEY_PASSWORD")
        }
    }
}
```

**Update the release build type** to use the CI signing config when available, falling back to debug for local builds:

```kotlin
release {
    isMinifyEnabled = true
    isShrinkResources = true
    signingConfig = if (System.getenv("SIGNING_KEYSTORE_PATH") != null) {
        signingConfigs.getByName("release")
    } else {
        signingConfigs.getByName("debug")  // Local dev fallback
    }
    proguardFiles(
        getDefaultProguardFile("proguard-android-optimize.txt"),
        "proguard-rules.pro"
    )
}
```

**Key points:**
- The environment variable `SIGNING_KEYSTORE_PATH` acts as the presence check — if set, CI signing is active
- Four env vars: `SIGNING_KEYSTORE_PATH` (file path to decoded keystore), `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`
- Local builds without env vars fall back to debug keystore (preserving current behavior)
- No keystore file is committed to the repository
- Do NOT change any other part of the build file (namespace, SDK versions, dependencies, etc.)

<task type="auto">
  <name>Task 2: Create GitHub Actions workflow with split CI strategy</name>
  <files>.github/workflows/build.yml</files>
  <action>
Create `.github/workflows/build.yml` with a single workflow file using `if:` conditions to implement a split CI strategy:
- **On push/PR to main:** lint + debug APK build only (fast feedback)
- **On tag push (v*):** full pipeline — lint, debug APK, release APK (signed), artifact upload

**Workflow structure:**

```yaml
name: Build

on:
  push:
    branches: [main]
    tags: ['v*']
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      # 1. Checkout with submodules (whisper.cpp is a git submodule)
      - uses: actions/checkout@v4
        with:
          submodules: recursive

      # 2. Set up JDK 17 (required by AGP 8.7.3)
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17

      # 3. Set up Android SDK, NDK, and CMake
      #    Use the official Android setup action
      - name: Setup Android SDK
        uses: android-actions/setup-android@v3

      - name: Install NDK and CMake
        run: |
          sdkmanager --install "ndk;26.1.10909125" "cmake;3.22.1"

      # 4. Cache Gradle dependencies
      - uses: actions/cache@v4
        with:
          path: |
            ~/.gradle/caches
            ~/.gradle/wrapper
          key: gradle-${{ hashFiles('**/*.gradle.kts', '**/gradle-wrapper.properties', '**/libs.versions.toml') }}
          restore-keys: |
            gradle-

      # 5. Make gradlew executable
      - name: Make gradlew executable
        run: chmod +x gradlew

      # 6. Run Android lint (ALWAYS — every push, PR, and tag)
      - name: Run lint
        run: ./gradlew lintDebug

      # 7. Build debug APK (ALWAYS — every push, PR, and tag)
      - name: Build debug APK
        run: ./gradlew assembleDebug

      # === TAG-ONLY STEPS BELOW (v* tags trigger full pipeline) ===

      # 8. Decode keystore and configure signing environment (TAG ONLY)
      - name: Configure release signing
        if: startsWith(github.ref, 'refs/tags/')
        env:
          KEYSTORE_BASE64: ${{ secrets.KEYSTORE_BASE64 }}
          KEYSTORE_PASSWORD: ${{ secrets.KEYSTORE_PASSWORD }}
          KEY_ALIAS: ${{ secrets.KEY_ALIAS }}
          KEY_PASSWORD: ${{ secrets.KEY_PASSWORD }}
        run: |
          echo "$KEYSTORE_BASE64" | base64 -d > "$GITHUB_WORKSPACE/release.keystore"
          echo "SIGNING_KEYSTORE_PATH=$GITHUB_WORKSPACE/release.keystore" >> "$GITHUB_ENV"
          echo "SIGNING_STORE_PASSWORD=$KEYSTORE_PASSWORD" >> "$GITHUB_ENV"
          echo "SIGNING_KEY_ALIAS=$KEY_ALIAS" >> "$GITHUB_ENV"
          echo "SIGNING_KEY_PASSWORD=$KEY_PASSWORD" >> "$GITHUB_ENV"

      # 9. Build release APK (TAG ONLY)
      - name: Build release APK
        if: startsWith(github.ref, 'refs/tags/')
        run: ./gradlew assembleRelease

      # 10. Upload debug APK artifact (TAG ONLY)
      - name: Upload debug APK
        if: startsWith(github.ref, 'refs/tags/')
        uses: actions/upload-artifact@v4
        with:
          name: app-debug
          path: app/build/outputs/apk/debug/app-debug.apk

      # 11. Upload release APK artifact (TAG ONLY)
      - name: Upload release APK
        if: startsWith(github.ref, 'refs/tags/')
        uses: actions/upload-artifact@v4
        with:
          name: app-release
          path: app/build/outputs/apk/release/app-release*.apk
```

**Key design decisions:**
- **Single workflow file with `if:` conditions** — NOT two separate workflows. The split is implemented via `if: startsWith(github.ref, 'refs/tags/')` on release/signing/upload steps
- **Split CI strategy:**
  - Push/PR to main: lint + assembleDebug only (~fast feedback, minutes not 10+)
  - Tag push (v*): lint + assembleDebug + assembleRelease + signing + artifact upload (full pipeline)
- **`tags: ['v*']`** in the `on.push` trigger — only tags matching the `v*` pattern trigger tag-conditional steps
- **Single job** — keeps it simple; steps are conditional, not separate jobs
- **`submodules: recursive`** — whisper.cpp is a git submodule, must be checked out for CMake native build
- **NDK 26.1.10909125** — exact version matching `app/build.gradle.kts` `ndkVersion`
- **CMake 3.22.1** — exact version matching `app/build.gradle.kts` cmake version
- **JDK 17** — required by AGP 8.7.3 (Gradle 8.9)
- **`lintDebug`** — runs lint on debug variant (catches all lint issues without needing release signing)
- **Keystore decoded from base64** — `KEYSTORE_BASE64` secret holds base64-encoded .jks; decoded to a temp file at runtime, never committed
- **Tag-conditioned signing** — the signing step uses `if: startsWith(github.ref, 'refs/tags/')`, NOT a secrets-presence check. This is cleaner: secrets are expected to exist for the repo, and the condition is whether we're doing a release (tag) or just CI (push/PR).
- **Gradle cache** — keyed on all build files for faster incremental builds
- **upload-artifact@v4** — uploads both APKs as separate downloadable artifacts, tag-only
- **`android-actions/setup-android@v3`** — sets up Android SDK command-line tools so `sdkmanager` is available

**Do NOT:**
- Create two separate workflow files — this is a single file with `if:` conditions
- Add deploy/release steps — this is a CI build pipeline only
- Use `gradle-build-action` — the cache step + direct gradlew invocation is simpler and more transparent
- Pin NDK/CMake to different versions than what build.gradle.kts specifies
- Use `if: ${{ secrets.KEYSTORE_BASE64 != '' }}` — use `startsWith(github.ref, 'refs/tags/')` instead
