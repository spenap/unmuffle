# Requirements Archive: TransChat v1.0 MVP

**Defined:** 2026-02-27
**Archived:** 2026-02-27
**Status:** All v1 requirements complete (12/12)
**Core Value:** Transcribe shared voice messages locally and privately — no cloud, no data leaks.

## v1 Requirements — All Complete

### Share Intent

- [x] **SHARE-01**: App appears in Android share sheet when user shares audio from WhatsApp/Telegram
- [x] **SHARE-02**: App accepts `audio/*` and `application/octet-stream` MIME types
- [x] **SHARE-03**: Audio bytes copied from content URI to private storage before processing

### Transcription

- [x] **TRANS-01**: Audio decoded from OGG/Opus to 16kHz mono PCM using platform MediaCodec
- [x] **TRANS-02**: Whisper small multilingual model transcribes audio on-device via whisper.cpp JNI
- [x] **TRANS-03**: Transcription runs off main thread (no ANR)
- [x] **TRANS-04**: Anti-hallucination via Kotlin post-processing (original spec said whisper params; adjusted after testing showed q5_1 model filtered real speech)

### Output

- [x] **OUT-01**: Transcript available via explicit Copy button (original spec said auto-clipboard; adjusted per user privacy decision)
- [x] **OUT-02**: Transcript displayed on result screen with Copy/Share buttons (original spec said toast; evolved to full result screen per user decision)

### Model Management

- [x] **MODEL-01**: Whisper small model (ggml-small-q5_1.bin, ~190MB) downloaded on first launch
- [x] **MODEL-02**: Download progress shown to user
- [x] **MODEL-03**: Model stored in app private storage (filesDir)

## Requirement Evolution Notes

Three requirements evolved during implementation:

1. **TRANS-04** (Anti-hallucination): Original spec called for `no_timestamps=true` and `no_speech_thold=0.6` as whisper params. Testing revealed `no_timestamps=true` caused the q5_1 quantized model to filter real speech. Replaced with Kotlin post-processing (`HallucinationFilter`) that detects non-speech markers and repetitive hallucination. Superior outcome.

2. **OUT-01** (Clipboard): Original spec called for auto-copy to clipboard. User decided against this during Phase 3 discuss-phase — clipboard is readable by other apps on older Android. Replaced with explicit Copy button. Privacy improvement.

3. **OUT-02** (Toast): Original spec called for toast notification. User decided on a full result screen with transcript display, Copy button, and Share button. Strictly superior to a toast.
