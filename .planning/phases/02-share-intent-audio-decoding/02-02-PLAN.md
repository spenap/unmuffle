**File 1: AudioDecoder.kt**

Data class for decode output:
```kotlin
data class DecodedAudio(
    val samples: ShortArray,   // interleaved int16 PCM at native decoder rate
    val sampleRate: Int,       // e.g. 48000 for Opus
    val channels: Int          // 1 = mono, 2 = stereo
)
```

Object `AudioDecoder` with a single public method:
```kotlin
object AudioDecoder {
    fun decode(filePath: String): DecodedAudio?
}
```

**decode() implementation using MediaExtractor + MediaCodec (synchronous pattern):**

1. Create `MediaExtractor()`, call `setDataSource(filePath)`.
2. Find the first audio track: iterate `0 until trackCount`, get format, check `KEY_MIME` starts with "audio/". If no audio track found, log warning and return null.
3. `selectTrack(audioTrackIndex)`.
4. Create decoder: `MediaCodec.createDecoderByType(mime)`, `configure(format, null, null, 0)`, `start()`.
5. Decode loop (synchronous polling pattern from research):
   - Feed input buffers from extractor until end of stream (`readSampleData` returns -1).
   - Use `dequeueInputBuffer(10_000)` timeout of 10ms.
   - When input exhausted, queue `BUFFER_FLAG_END_OF_STREAM`.
   - Drain output buffers with `dequeueOutputBuffer(bufferInfo, 10_000)`.
   - Handle `INFO_OUTPUT_FORMAT_CHANGED`: read `KEY_SAMPLE_RATE` and `KEY_CHANNEL_COUNT` from `codec.outputFormat`. This is CRITICAL -- Opus always outputs 48kHz regardless of source rate.
   - Handle `INFO_OUTPUT_BUFFERS_CHANGED`: no-op (deprecated since API 21).
   - Handle `INFO_TRY_AGAIN_LATER`: continue loop (timeout, just retry).
   - For positive output index: extract bytes from output buffer into a `MutableList<ByteArray>`, then `releaseOutputBuffer(index, false)`.
   - Check `BUFFER_FLAG_END_OF_STREAM` to exit loop.
6. `codec.stop()`, `codec.release()`, `extractor.release()`.
7. Concatenate all byte chunks into a single `ByteArray`.
8. Convert to `ShortArray`: read pairs of bytes as little-endian int16.
   ```kotlin
   val shorts = ShortArray(totalBytes.size / 2)
   ByteBuffer.wrap(totalBytes).order(ByteOrder.LITTLE_ENDIAN).asShortBuffer().get(shorts)
   ```
9. Return `DecodedAudio(shorts, outputSampleRate, outputChannels)`.

**Wrap entire decode in try-catch.** On any Exception, log the error, release codec and extractor in finally block, return null.

**File 2: PcmResampler.kt**

Object `PcmResampler` with methods:

```kotlin
object PcmResampler {
    fun toWhisperFormat(decoded: DecodedAudio): FloatArray?
}
```

**toWhisperFormat implementation:**

1. Start with `decoded.samples` (ShortArray).
2. If `decoded.channels == 2`, mix to mono: average interleaved L/R pairs.
   ```kotlin
   fun stereoToMono(stereo: ShortArray): ShortArray {
       val mono = ShortArray(stereo.size / 2)
       for (i in mono.indices) {
           mono[i] = ((stereo[i * 2].toInt() + stereo[i * 2 + 1].toInt()) / 2).toShort()
       }
       return mono
   }
   ```
3. If `decoded.sampleRate != 16000`, resample to 16kHz.
   - Use linear interpolation resampler that handles ANY input rate (not just 3:1):
   ```kotlin
   fun resample(samples: ShortArray, fromRate: Int, toRate: Int): ShortArray {
       if (fromRate == toRate) return samples
       val ratio = fromRate.toDouble() / toRate.toDouble()
       val outputSize = (samples.size / ratio).toInt()
       val output = ShortArray(outputSize)
       for (i in 0 until outputSize) {
           val srcPos = i * ratio
           val srcIndex = srcPos.toInt()
           val frac = srcPos - srcIndex
           val s0 = samples[srcIndex.coerceAtMost(samples.size - 1)].toInt()
           val s1 = samples[(srcIndex + 1).coerceAtMost(samples.size - 1)].toInt()
           output[i] = (s0 + (s1 - s0) * frac).toInt().toShort()
       }
       return output
   }
   ```
   This handles 48kHz->16kHz (ratio 3.0), 44.1kHz->16kHz (ratio 2.75625), and any other rate.
4. Convert int16 to float32 normalized to [-1.0, 1.0]:
   ```kotlin
   fun shortToFloat(shorts: ShortArray): FloatArray {
       return FloatArray(shorts.size) { shorts[it].toFloat() / 32768.0f }
   }
   ```
5. Chain: stereoToMono (if needed) -> resample (if needed) -> shortToFloat.
6. Return the FloatArray. If input samples are empty, return null.
7. Log the pipeline: "PcmResampler: {channels}ch {sampleRate}Hz -> 1ch 16000Hz, {inputSamples} -> {outputSamples} samples ({durationSeconds}s)"

**File 3: WavWriter.kt**

Object `WavWriter` with a single method:
```kotlin
object WavWriter {

}
```

Write a standard 44-byte RIFF/WAV header followed by int16 PCM data. Use the exact header format from the research code examples:
- RIFF chunk: "RIFF" + (36 + dataSize) + "WAVE"
- fmt sub-chunk: "fmt " + 16 + AudioFormat=1(PCM) + channels + sampleRate + byteRate + blockAlign + bitsPerSample=16
- data sub-chunk: "data" + dataSize + raw int16 samples in little-endian

Helper functions `intToLittleEndian(Int): ByteArray` and `shortToLittleEndian(Int): ByteArray` as private.

All values written via `BufferedOutputStream` for performance.

**Add private decode function:**

```kotlin
private fun decodeToWhisperPcm(audioFile: File): FloatArray? {
    // Step 1: Decode compressed audio to raw PCM
    val decoded = AudioDecoder.decode(audioFile.absolutePath)
    if (decoded == null) {
        Log.e(TAG, "AudioDecoder.decode failed for ${audioFile.name}")
        return null
    }
    Log.i(TAG, "Decoded: ${decoded.samples.size} samples, ${decoded.sampleRate}Hz, ${decoded.channels}ch")

    // Step 2: Write verification WAV BEFORE resampling (original decoded rate)
    // This WAV can be adb-pulled and played on a computer to verify decode quality
    val wavFile = File(cacheDir, "audio/verify_${System.currentTimeMillis()}.wav")
    WavWriter.write(wavFile, decoded.samples, decoded.sampleRate, decoded.channels)
    Log.i(TAG, "Verification WAV written: ${wavFile.absolutePath} (${wavFile.length() / 1024}KB)")

    // Step 3: Resample to 16kHz mono float32 (Whisper input format)
    val pcm = PcmResampler.toWhisperFormat(decoded)
    if (pcm == null) {
        Log.e(TAG, "PcmResampler.toWhisperFormat returned null")
        return null
    }

    // Step 4: Write a second verification WAV at 16kHz for Whisper-ready verification
    val resampled16 = ShortArray(pcm.size) { (pcm[it] * 32768f).toInt().coerceIn(-32768, 32767).toShort() }
    val wavFile16 = File(cacheDir, "audio/verify_16khz_${System.currentTimeMillis()}.wav")
    WavWriter.write(wavFile16, resampled16, 16000, 1)
    Log.i(TAG, "16kHz verification WAV: ${wavFile16.absolutePath} (${wavFile16.length() / 1024}KB)")

    return pcm
}
```
