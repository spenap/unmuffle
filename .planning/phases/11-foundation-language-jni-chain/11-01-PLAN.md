- `TINY`: filename=`ggml-tiny-q5_1.bin`, url=`https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny-q5_1.bin`, sha256=`818710568da3ca15689e31a743197b520007872ff9576237bda97bd1b469c3d7`, sizeBytes=`33_739_776L` (approximate, add comment), displayName=`Tiny (~32 MB, faster)`

**SettingsRepository.kt** — Kotlin `object` wrapping `SharedPreferences`. MUST use `context.applicationContext.getSharedPreferences(...)` to avoid activity context leaks (see Pitfall 3 in research). Prefs name: `unmuffle_prefs`. Methods:
- `getLanguage(context: Context): String` — returns stored language or `"auto"` default
- `setLanguage(context: Context, languageCode: String)` — uses `.apply()` (not `.commit()`)
- `isLanguageRemembered(context: Context): Boolean` — returns false by default
- `setLanguageRemembered(context: Context, remembered: Boolean)`
- `getModel(context: Context): WhisperModel` — returns stored model or `WhisperModel.SMALL` default
- `setModel(context: Context, model: WhisperModel)`

Use `private const val` for all key strings (KEY_LANGUAGE = "pref_language", KEY_LANGUAGE_REMEMBERED = "pref_language_remembered", KEY_MODEL = "pref_model"). Use `WhisperModel.entries.find { it.name == name }` (not deprecated `.values()`).
