**Step 2 — Rewrite proguard-rules.pro (COMPLETE REPLACEMENT, not incremental edit):**

Replace the entire contents of `app/proguard-rules.pro` with:

```proguard
# ============================================================================
# TransChat ProGuard/R8 Rules
# ============================================================================
# R8 mode: code shrinking ON, obfuscation OFF, resource shrinking ON
# Readable class names for crash reports (open-source F-Droid app)
# ============================================================================

# --- Global flags -----------------------------------------------------------
-dontobfuscate

# --- JNI bridge -------------------------------------------------------------
# WhisperLib: C++ resolves methods by fully-qualified JNI name
# (Java_com_simonpena_transchat_WhisperLib_00024Companion_*)
# Both the class and Companion must survive with original names and members
-keep class com.simonpena.transchat.WhisperLib { *; }
-keep class com.simonpena.transchat.WhisperLib$Companion { *; }

# --- Sealed class hierarchies -----------------------------------------------
# R8 can trace these via when() expressions, but we keep them defensively.
# Cost: negligible. Risk without: potential ClassNotFoundException at runtime.

# DownloadViewModel.State and subclasses
-keep class com.simonpena.transchat.DownloadViewModel$State { *; }
-keep class com.simonpena.transchat.DownloadViewModel$State$* { *; }

# UiState and subclasses (top-level sealed class in TranscriptionViewModel.kt)
-keep class com.simonpena.transchat.UiState { *; }
-keep class com.simonpena.transchat.UiState$* { *; }

# AudioCopier.CopyResult and subclasses
-keep class com.simonpena.transchat.AudioCopier$CopyResult { *; }
-keep class com.simonpena.transchat.AudioCopier$CopyResult$* { *; }

# --- Phase 5: Progress callback (uncomment when interface is added) ----------
# -keep class com.simonpena.transchat.ProgressCallback { *; }

# --- Notes -------------------------------------------------------------------
# ViewModels: Kept automatically by lifecycle-viewmodel library consumer rules
#   (-keep class * extends AndroidViewModel { <init>(Application); })
# Activities: Kept automatically by R8 via AndroidManifest.xml entry points
# Native methods: Kept by proguard-android-optimize.txt default rules
#   (-keepclasseswithmembernames,includedescriptorclasses class * { native <methods>; })
```

Critical: Do NOT leave any of the old rules. The old blanket keep (`-keep class com.simonpena.transchat.** { *; }`) and the redundant native method rules MUST be completely removed. This is a full file replacement.

**Step 3 — Add resource shrinking to build.gradle.kts:**

In `app/build.gradle.kts`, add `isShrinkResources = true` to the `release` block, immediately after `isMinifyEnabled = true` (line 47). The release block should become:

```kotlin
release {
    isMinifyEnabled = true
    isShrinkResources = true
    signingConfig = signingConfigs.getByName("debug")
    proguardFiles(
        getDefaultProguardFile("proguard-android-optimize.txt"),
        "proguard-rules.pro"
    )
}
```

Only this one line changes in build.gradle.kts. Do not modify anything else.

**Step 4 — Build new release APK and compare size:**
Run `./gradlew assembleRelease` again. Record the new APK size. Calculate and note the delta (expected: smaller due to library tree-shaking). Both sizes will be documented in the SUMMARY.md.

**What NOT to do:**
- Do NOT add `-keep` rules for Activities (R8 keeps them via AndroidManifest.xml automatically)
- Do NOT add `-keep` rules for ViewModels (lifecycle-viewmodel library ships consumer rules)
- Do NOT add redundant native method rules (proguard-android-optimize.txt covers these)
- Do NOT use `-keepnames` instead of `-keep` — we want full member preservation for JNI and sealed classes
