<task type="auto">
  <name>Task 2: Create comprehensive README.md</name>
  <files>README.md</files>
  <action>
Create `README.md` at the repository root with the following sections (in order):

**1. Title and badges area**
- `# TransChat` as the heading
- One-line description: "Transcribe shared voice messages locally and privately — no cloud, no data leaks."

**2. Features section**
- Heading: `## Features`
- Bullet list covering:
  - Share target for WhatsApp, Telegram, and any app that shares audio files
  - On-device transcription using whisper.cpp (no internet required)
  - Multilingual support (auto-detects language, tested with Spanish)
  - Real-time progress bar during transcription (0-100%)
  - Copy and Share buttons for the transcript result
  - Anti-hallucination filtering for silent/noise audio
  - Privacy-first: zero network permissions declared in manifest
  - Small footprint: ~5.4 MB APK (arm64-v8a release build)

**3. Privacy section**
- Heading: `## Privacy`
- Explain that TransChat has zero network permissions (not even INTERNET except for model download)
- Audio never leaves the device
- No analytics, no telemetry, no tracking
- Model download is the only network operation (one-time, over WiFi by default)
- Transcripts are ephemeral — not stored on disk

**4. Screenshots section**
- Heading: `## Screenshots`
- A table or horizontal layout showing 5 screenshots with captions
- Use paths: `docs/screenshots/01-model-download.png`, `docs/screenshots/02-ready-state.png`, `docs/screenshots/03-share-target.png`, `docs/screenshots/04-progress-bar.png`, `docs/screenshots/05-result.png`
- Captions: Model Download, Ready State, Share Target, Progress Bar, Result
- Use markdown image syntax with width hints for GitHub rendering:
  ```
  | Model Download | Ready State | Share Target | Progress Bar | Result |
  |:-:|:-:|:-:|:-:|:-:|
  | <img src="docs/screenshots/01-model-download.png" width="160"/> | ... |
  ```

**5. How It Works section**
- Heading: `## How It Works`
- Brief numbered list:
  1. Share a voice message from WhatsApp, Telegram, or any messaging app
  2. TransChat decodes the audio (OGG/Opus, MP3) via Android MediaCodec
  3. Audio is resampled to 16kHz mono for Whisper
  4. whisper.cpp runs on-device inference using the small multilingual model
  5. Post-processing filters hallucinations from silent/noise segments
  6. Read, copy, or share the transcript

**6. Build section**
- Heading: `## Building from Source`
- Sub-section `### Prerequisites`:
  - Android Studio Ladybug (2024.2) or later
  - Android SDK with compileSdk 34
  - Android NDK 26.1.10909125 (install via SDK Manager)
  - CMake 3.22.1 (install via SDK Manager)
  - Git (for submodule checkout)
- Sub-section `### Steps`:
  ```bash
  git clone --recurse-submodules https://github.com/simonpena/transchat.git
  cd transchat
  ```
  - If already cloned without submodules:
  ```bash
  git submodule update --init --recursive
  ```
  - Open in Android Studio, sync Gradle, select `arm64-v8a` device, run
  - Or from command line:
  ```bash
  ./gradlew assembleDebug
  ```
  - The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`

**7. Tech Stack section**
- Heading: `## Tech Stack`
- Table format:
  | Component | Version |

  | Whisper model | small multilingual q5_1 (~190 MB) |

  | Gradle / AGP | 8.9 / 8.7.3 |
  | NDK | 26.1 (r26) |
  | compileSdk / targetSdk | 34 |
  | minSdk | 26 (Android 8.0) |
