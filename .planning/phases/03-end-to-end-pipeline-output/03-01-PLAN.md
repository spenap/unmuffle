Create `HallucinationFilter.kt` in the transchat package as a stateless `object`.

Implements TRANS-04 via post-processing (NOT by modifying whisper params -- STATE.md documents that no_timestamps=true was reverted because it caused the q5_1 model to filter real speech).

The `filter(raw: String): String?` function:
1. Trim input. Return null if blank.
2. Check for known non-speech markers: `[BLANK_AUDIO]`, `[MUSIC]`, `[SILENCE]`, `(BEEPING)`, `(MUSIC)`, `(music)`. If the entire output after removing all bracketed/parenthesized markers is blank, return null.
3. Detect repetitive hallucination: if 6+ words and fewer than 1/3 unique words, return null.
4. Otherwise return the trimmed text.

Use a `MARKER_REGEX = Regex("""\[[\w\s_]+\]|\([\w\s_]+\)""")` to strip marker tokens.

Reference the complete implementation in 03-RESEARCH.md "Complete Hallucination Filter" section -- follow that code closely.

Do NOT modify any whisper.cpp params or whisper_jni.cpp. The anti-hallucination is purely Kotlin post-processing.

Create `TranscriptionViewModel.kt` in the transchat package.

**UiState sealed class** (defined at top level in same file):
```kotlin
sealed class UiState {
    object Processing : UiState()
    data class Success(val transcript: String) : UiState()
    data class NoSpeech(val message: String) : UiState()
    data class Error(val message: String) : UiState()
}
```

**TranscriptionViewModel** extends `AndroidViewModel(app)`:
- `private val _uiState = MutableStateFlow<UiState>(UiState.Processing)`
- `val uiState: StateFlow<UiState> = _uiState`
- `private val engine = WhisperEngine()`
- `private var inferenceJob: Job? = null`
- `private var audioFilePath: String? = null` (for cleanup)

**`fun startTranscription(audioPath: String)`:**
1. Store `audioFilePath = audioPath`
2. Launch on `viewModelScope`:
   a. Load model: `engine.loadModel(ModelManager.modelFile(getApplication()).absolutePath)`. If returns false, set `UiState.Error("Could not load model")` and return.
   b. Decode audio: call `AudioDecoder.decode(audioPath)` on Dispatchers.Default. If null, set `UiState.Error("Could not decode audio")` and return.
   c. Resample: call `PcmResampler.toWhisperFormat(decoded)` on same dispatcher. If null, set error and return.
   d. Transcribe: call `engine.transcribe(pcm)`. This already runs on Dispatchers.Default internally.
   e. Filter: call `HallucinationFilter.filter(raw)`.
   f. If filter returns null: set `UiState.NoSpeech("No speech detected")`.
   g. If filter returns text: set `UiState.Success(text)`.
3. Wrap entire launch body in try/catch for CancellationException (rethrow) and Exception (set UiState.Error).
4. Store the Job in `inferenceJob`.

**`fun cancelInference()`:**
- Call `inferenceJob?.cancel()`. The JNI call is blocking and not cooperatively cancellable (this is a known MVP limitation documented in RESEARCH.md). The coroutine will be marked cancelled but the native call completes in the background.

**`override fun onCleared()`:**
- Cancel inferenceJob
- Launch `viewModelScope.launch { engine.release() }` -- but viewModelScope is cancelled in onCleared, so instead use `runBlocking(Dispatchers.Default) { engine.release() }` or just call cleanup synchronously. Actually, since onCleared cancels viewModelScope, use a GlobalScope or just accept the leak for MVP. Simplest approach: call `inferenceJob?.cancel()` and rely on the engine being GC'd. The native memory will be freed when the process dies (single-use activity pattern).
- Delete cached audio file: `audioFilePath?.let { File(it).delete() }`. This handles cleanup that ShareReceiverActivity used to do in onDestroy.
- Delete any verification WAV files in cacheDir/audio/ (Phase 2 debugging artifacts -- remove from production path).

**Important threading note:** The decode step (AudioDecoder.decode + PcmResampler.toWhisperFormat) must run on Dispatchers.Default via `withContext`, not on the main thread. The transcribe call already handles its own dispatching internally. To be safe, wrap the entire pipeline (decode + resample + transcribe) in `withContext(Dispatchers.Default)` -- but note that `engine.loadModel()` and `engine.transcribe()` already use `withContext(Dispatchers.Default)` internally, so calling them from within a Default context is fine (coroutines handle nested dispatching).

**Startup guard:** Check `savedInstanceState == null` is done in the Activity, NOT the ViewModel. The ViewModel's startTranscription is called once. If the activity is recreated due to config change, the ViewModel survives and the existing state is observed.

            when (state) {

                    resultGroup.visibility = View.GONE
                    noSpeechGroup.visibility = View.GONE
