7. Update the `is UiState.Processing` branch in the state collector (lines 72-77). Replace:
```kotlin
                        is UiState.Processing -> {

                            resultGroup.visibility = View.GONE
                            noSpeechGroup.visibility = View.GONE
                            errorGroup.visibility = View.GONE
```

With:
```kotlin
                        is UiState.Processing -> {
                            progressGroup.visibility = View.VISIBLE
                            resultGroup.visibility = View.GONE
                            noSpeechGroup.visibility = View.GONE
                            errorGroup.visibility = View.GONE

                            if (state.progress < 0) {
                                // Pre-inference: indeterminate spinner
                                progressSpinner.isIndeterminate = true
                                tvStatus.text = "Transcribing..."
                            } else {
                                // During inference: determinate progress
                                progressSpinner.isIndeterminate = false
                                progressSpinner.setProgressCompat(state.progress, true)
                                tvStatus.text = "Transcribing... ${state.progress}%"
                            }
                        }
```
Key details:
- `state.progress` is available via smart cast from `is UiState.Processing`
- `setProgressCompat(progress, true)` — the `true` enables smooth animation and handles the indeterminate-to-determinate transition automatically on the first call
- Do NOT use `setProgress()` (without compat) — it skips the smooth transition
- The default `android:max="100"` on ProgressBar matches whisper.cpp's 0-100 range
