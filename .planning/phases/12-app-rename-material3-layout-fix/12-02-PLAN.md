  <action>
1. **Material library version bump** in `gradle/libs.versions.toml`:
   - `material = "1.12.0"` -> `material = "1.13.0"`

2. **Theme migration** in `app/src/main/res/values/themes.xml`:
   Replace the file content with:
   ```xml
   <?xml version="1.0" encoding="utf-8"?>
   <resources>
       <style name="Theme.Unmuffle" parent="Theme.Material3.DayNight.NoActionBar">
       </style>

       <!-- Transparent theme for headless activities (share receiver, router) -->
       <style name="Theme.Unmuffle.Transparent" parent="Theme.Material3.DayNight.NoActionBar">
           <item name="android:windowIsTranslucent">true</item>
           <item name="android:windowBackground">@android:color/transparent</item>
           <item name="android:windowContentOverlay">@null</item>
           <item name="android:windowNoTitle">true</item>
           <item name="android:windowIsFloating">true</item>
           <item name="android:backgroundDimEnabled">false</item>
       </style>
   </resources>
   ```
   Key change: Both parent themes change from `Theme.MaterialComponents.*` to `Theme.Material3.DayNight.NoActionBar`. This eliminates the action bar on ALL activities, which is the root cause fix for FIX-01.

3. **Create UnmuffleApplication.kt** at `app/src/main/java/com/simonpena/unmuffle/UnmuffleApplication.kt`:
   ```kotlin
   package com.simonpena.unmuffle

   import android.app.Application
   import com.google.android.material.color.DynamicColors

   class UnmuffleApplication : Application() {
       override fun onCreate() {
           super.onCreate()
           DynamicColors.applyToActivitiesIfAvailable(this)
       }
   }
   ```

4. **Register UnmuffleApplication** in `app/src/main/AndroidManifest.xml`:
   Add `android:name=".UnmuffleApplication"` to the `<application>` element (before or after `android:label`).

5. **Update textAppearance attributes** in all 4 layout XMLs. Apply these replacements:

   `activity_transcription.xml` (5 replacements):
   - `?attr/textAppearanceBody1` -> `?attr/textAppearanceBodyLarge` (3 occurrences — progress text, transcript text, error text)
   - `?attr/textAppearanceHeadline6` -> `?attr/textAppearanceTitleLarge` (1 occurrence — no-speech title)
   - `?attr/textAppearanceBody2` -> `?attr/textAppearanceBodyMedium` (1 occurrence — no-speech body)

   `activity_ready.xml` (2 replacements):
   - `?attr/textAppearanceHeadline5` -> `?attr/textAppearanceHeadlineMedium` (1 occurrence — heading)
   - `?attr/textAppearanceBody1` -> `?attr/textAppearanceBodyLarge` (1 occurrence — body)

   `activity_download.xml` (3 replacements):
   - `?attr/textAppearanceBody1` -> `?attr/textAppearanceBodyLarge` (1 occurrence — body)
   - `?attr/textAppearanceCaption` -> `?attr/textAppearanceBodySmall` (2 occurrences — captions)

   `activity_smoke_test.xml` (1 replacement):
   - `?attr/textAppearanceHeadline6` -> `?attr/textAppearanceTitleLarge` (1 occurrence — title)

6. **Replace plain Button with MaterialButton** in:
   - `activity_download.xml`: Replace `<Button` with `<com.google.android.material.button.MaterialButton` (opening and closing tags)
   - `activity_smoke_test.xml`: Replace `<Button` with `<com.google.android.material.button.MaterialButton` (opening and closing tags)

   Do NOT change `activity_transcription.xml` — it already uses `MaterialButton`.

7. Commit with message: `feat(12): migrate to Material 3 theme with dynamic color and layout fix`
